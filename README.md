# فوروارد خودکار پیام‌های خاموشی از @Bargheman1_bot به گروه‌های تلگرام

## چیدمان
- `login_once.py` — فقط یک‌بار، روی کامپیوتر خودتان اجرا می‌شود تا session بسازید.
- `forwarder.py` — اسکریپت اصلی؛ توسط GitHub Actions هر ۵ دقیقه اجرا می‌شود.
- `groups.json` / `state.json` — خودکار ساخته و در ریپو نگه‌داری می‌شوند.

## مراحل راه‌اندازی

### ۱. گرفتن API_ID و API_HASH
به https://my.telegram.org بروید → با شماره موبایل‌تان وارد شوید → "API development tools" → فرم را پر کنید (App title: هرچی، Platform: Other) → دو مقدار `api_id` و `api_hash` را یادداشت کنید.

### ۲. ساخت Session (فقط یک‌بار، روی کامپیوتر خودتان)
```bash
pip install telethon
python login_once.py
```
شماره موبایل و کدی که تلگرام برایتان می‌فرستد را وارد کنید. در پایان یک رشته‌ی طولانی چاپ می‌شود — آن را کپی کنید.

### ۳. ساخت ریپوی گیت‌هاب خصوصی
این فایل‌ها را در آن قرار دهید (به جز `login_once.py` که فقط محلی لازم است، ولی مشکلی هم ندارد اگر باشد).

### ۴. تنظیم Secrets
در **Settings → Secrets and variables → Actions** این‌ها را اضافه کنید:
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_SESSION` — همان رشته‌ای که از مرحله‌ی ۲ گرفتید
- `ACTIVATION_CODE` — یک رشته‌ی دلخواه و خصوصی، مثلاً `home-power-x7Qz2m`

### ۵. فعال‌سازی گروه‌ها
شما (با همین اکانت شخصی‌تان) در هر گروهی که می‌خواهید پیام‌ها را دریافت کند بنویسید:
```
/activate <همان ACTIVATION_CODE>
```
طی حداکثر ۵ دقیقه، در همان گروه پیام تایید دریافت می‌کنید.

### ۶. اتصال به ربات منبع
حتماً یک‌بار (دستی) با `@Bargheman1_bot` چت کرده و شماره قبض‌تان را ثبت کرده باشید (طبق چیزی که قبلاً امتحان کردید)، چون فوروارد فقط پیام‌های *جدید* از آن ربات را می‌گیرد.

## نکات امنیتی
- `TELEGRAM_SESSION` معادل رمز اکانت شماست — فقط در GitHub Secrets نگه دارید، هرگز در کد یا چت قرار ندهید.
- ریپو را **Private** نگه دارید.
- `ACTIVATION_CODE` را فقط به اعضای مورد اعتمادتان بدهید.
